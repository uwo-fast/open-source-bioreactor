# The OpenSCAD libraries this model needs, and the exact revision of each.
#
# Format: <name> <https-url> <ref>
#
# `name` is the directory the library is installed as, and it must match what
# the .scad files `use` or `include` - `NopSCADlib/core.scad` needs the checkout
# to be called NopSCADlib and nothing else.
#
# `ref` IS A TAG OR A COMMIT, NEVER A BRANCH. A library pinned to a branch makes
# "it renders here" a statement about a moving target, which is the whole reason
# this file exists: the model built on this machine for months and could not
# build anywhere else, because these four were installed globally and nothing in
# the repository said so.
#
# scripts/install-libraries.sh reads this. It clones over SSH and falls back to
# HTTPS, so a machine with a key gets one and a machine without - CI - gets the
# other, from the same line here.
#
# Tags where upstream publishes them, commit SHAs where it does not. NopSCADlib
# and bayonet-lock-scad publish tags; the others have no tags and no releases,
# so a SHA is the only honest pin. Read from the upstream repositories on
# 2026-09-09, and bayonet-lock-scad again on 2026-11-13.
#
# NOTE ON bayonet-lock-scad: custom/bayonet_port.scad asserts it is ">= 0.11.0".
# v0.12.0 is 0.11.1 (95953cc, which this pinned before) plus two parameter
# checks - a sweep that leaves the lock no turn stop, and a channel that breaks
# out of the bottom face - and bayonet_locked_rotation(); its geometry is
# unchanged, so tests/seams.txt still holds. 0.11.1 is the release that stopped
# the lock's entry transition leaving coincident faces, and the lid closes
# cleanly from it.
#
# NOTE ON turbidity-sensor AND syringe-actuator: scad/custom/sampler.scad builds on the
# probe board's library (hardware/probe/probe.scad) and on the actuator's layout
# (cad/main.scad). Neither publishes tags, so each is pinned to the commit on its main
# that carries what the sampler reads: the probe's measured heights and optical axis, and the actuator's
# front_face(), front_x() and tip_x().
#
# turbidity-sensor must also be at or after its relicensing to GPL-3.0-or-later
# (uwo-fast/turbidity-sensor#37). Before it the probe library is GPL-3.0-only, and
# LICENSING.md's GPL-3.0-or-later grant over the sampler does not hold.
